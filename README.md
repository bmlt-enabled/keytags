# Virtual Keytags

Send someone a virtual NA clean-time keytag — a keepsake card celebrating a milestone — or
put one full-screen on screen-share during an online meeting.

**How it works:** open the app, pick a milestone (or enter a clean date), add a name and a
short message, then **share the link** or **download the image**.

**Private by design.** No accounts, no server, nothing stored. The whole card lives inside
the link you share, so it exists only where you send it.

6 languages · optional specialty long-term tags · works on phone and desktop.
